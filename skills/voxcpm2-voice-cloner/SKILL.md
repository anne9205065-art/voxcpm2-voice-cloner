# VoxCPM2 Voice Cloner 技能包

本技能包為 AI Agent（Codex、OpenCord、Claude Code、Antigravity 等）提供完整的語音生成與聲音克隆能力。
核心理念：**完全走自然語言對話**。人類使用者只需說出想說的話與指定的聲音，Agent 自動解析並調用本機工具產出高品質自然音檔。

---

## 🎯 觸發情境（何時使用）

當使用者提出以下或類似的自然語言需求時自動啟用：
- 「用[聲音名稱]說『......』」
- 「請幫我朗讀這段文字，聲音要很舒服好聽」
- 「讓[角色A]跟[角色B]對話一段......」
- 「目前有哪些聲音可以用？」
- 「我想錄製/加入新的聲音」

---

## 🛠️ 工具調用方式（Agent 自動執行）

> ⚠️ **執行環境路徑**：
> - Windows: `.\.venv\Scripts\python.exe`（或環境中的 `python`）
> - Linux/macOS: `./.venv/bin/python`（或 `python3`）

### 1. 單一語音克隆生成 (`clone.py`)
```bash
python clone.py "<要說的文字>" --voice "<聲音名稱>"
```
- **預設輸出**：`output/cloned_voice.wav`
- 若使用者未指定聲音名稱，預設自動採用 `voices/` 目錄內的第一個可用聲音。
- 也可以透過 `--output <自訂路徑.wav>` 指定輸出檔名。

### 2. 多角色對話生成 (`dialogue.py`)
```bash
python dialogue.py --a "<說話者A>" --b "<說話者B>"
```
- **預設輸出**：`output/dialogue_<A>_<B>.wav`
- 支援編輯 `dialogue.py` 中的 `dialogue` 清單來客製化完整對白內容。

### 3. 查詢可用聲音
```bash
ls voices/
```
列出 `voices/` 目錄下的所有子資料夾名稱即為可用的聲音庫。

### 4. 錄製與加入新聲音
引導使用者啟動錄音介面：
```bash
python app.py
```
並告知在瀏覽器打開 `http://127.0.0.1:7860` 進行錄音或上傳音檔。

## ⚙️ 聲音結構與原理

每個聲音資料夾 `voices/<聲音名稱>/` 包含：
- `ref_voice.wav`：16kHz 單聲道參考音（5～15 秒，無背景雜音）。
- `prompt.txt`：該音檔的一字不差逐字稿。

當加入新聲音時，只要在 `voices/` 建立同名資料夾並放入這兩個檔案，Agent 就能立即在對話中調用。
